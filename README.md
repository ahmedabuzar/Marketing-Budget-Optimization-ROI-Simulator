# 📊 Marketing Budget Optimization & ROI Simulator (Power BI)

## 🔍 Project Overview
This project analyzes marketing performance across channels using Power BI and enables scenario-based budget planning through a What-If simulation.

The dashboard helps stakeholders understand:
- How marketing spend translates into revenue
- Which channels deliver the highest ROI
- How budget changes impact overall performance before execution

---

## 🛠 Tools & Skills Used
- Power BI
- Data Modeling
- DAX (Measures)
- KPI Design
- What-If Parameter Analysis
- Dashboarding & Business Storytelling

---

## 📈 Key Features
- KPI cards for Spend, Revenue, ROI, and Cost per Conversion
- Channel-wise performance analysis
- Monthly revenue trend analysis
- Campaign manager performance comparison
- Interactive budget what-if simulation
- Actionable business insights and recommendations

---

## 💡 Business Insights
- Google generates the highest revenue but requires higher spend, indicating scale-driven performance.
- Email delivers the highest ROI with lower spend, making it the most cost-efficient channel.
- Meta shows optimization potential before further budget scaling.
- Budget increases improve revenue, but ROI gains diminish beyond a point.

---

## 🧠 Recommendations
- Scale Google campaigns gradually while monitoring ROI.
- Maintain Email as a high-ROI, low-cost support channel.
- Optimize Meta campaigns before increasing spend.
- Use the budget simulator to test decisions before execution.
